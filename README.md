# Desktop Remoto — download

Installer di **Desktop Remoto**, app di assistenza remota multipiattaforma.
Scarica l'ultima versione dalla pagina [Releases](../../releases/latest):

| Sistema | File |
|---|---|
| macOS Apple Silicon | `Desktop.Remoto_<versione>_aarch64.dmg` |
| macOS Intel | `Desktop.Remoto_<versione>_x64.dmg` |
| Windows | `Desktop.Remoto_<versione>_x64-setup.exe` |
| Linux | `.AppImage` (si aggiorna da sola), `.deb`, `.rpm` |

Dopo l'installazione l'app si aggiorna dal pulsante **Aggiornamenti**.
Gli installer non sono ancora firmati: al primo avvio su macOS clic destro → *Apri*;
su Windows *Ulteriori informazioni* → *Esegui comunque*.

Questo repository contiene solo i pacchetti pubblicati; il codice sorgente è privato.
